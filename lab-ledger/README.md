# קופת המעבדה (lab-ledger)

אפליקציה (PWA) להכנסות, הוצאות ומלאי של מעבדת התיקונים.

## מה יש
- **4 סוגי הוצאות:** 📦 מלאי וחלקים · 🔁 קבועות · 🧾 משתנות · 🛠 השקעה בהקמה (לא יורדת מהרווח החודשי, נספרת ב"החזר ההשקעה").
- **רווח חודשי**, תקציב הוצאות שוטפות עם התראה, החזר ההשקעה וצפי בחודשים.
- **מלאי:** קנייה מסוג מלאי מוסיפה יחידות, תיקון שבוחר חלק מהמלאי מוריד אותו ומחשב את עלות החלק לבד. התראה כשנגמר / עומד להיגמר, הורדה ידנית (פגום/אבד), חיפוש.
- **רווח לכל תיקון** (התראה מתחת ל־40%), וניתוח לפי סוג תיקון בדוחות.
- **חיפוש קניות** לפי מוצר/ספק: מחיר אחרון, הכי זול, קישור "להזמנה" ו"רשום קנייה חוזרת". מחיר ליחידה והשוואה לפעם הזולה.
- תמונות (חשבונית, צילום מסך, חלק, מכשיר), ספק, קישור, הערה. העתקה לאקסל. הוספת כל הקבועות של החודש הקודם בלחיצה.

## איפה הכול יושב
- **Vercel:** פרויקט `lab-ledger`, Root Directory = `lab-ledger`, Ignored Build Step: `git diff --quiet HEAD^ HEAD -- .`
- **Supabase:** הפרויקט של החנות. טבלאות `ll_books`, `ll_tx`, דלי `ll-photos` (`supabase/schema.sql`, כבר הורץ).
  אין גישה ישירה לטבלאות, רק דרך פונקציות `ll_*` שמקבלות את מזהה הקופה.
- **גישה:** מזהה הקופה (הקישור הסודי) נשמר בטלפון. מכשיר נוסף: ⚙️ הגדרות → העתק קישור.
- הקוד של המסכים ב-`lib/ledger.js` (JS רגיל שמצייר את המסכים), נבנה מהתצוגה המקדימה שאושרה.

## משתני סביבה
`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` (כבר מוגדרים ב-Vercel).
