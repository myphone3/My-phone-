# מידע לחנות (meida)

אפליקציה (PWA) לכל המידע של החנות: קודים, IMEI, נקודות שירות, טלפונים, הוראות, מחירים.
משותפת לכל העובדים (כל אחד נכנס עם Google, המנהל מאשר), ומסודרת לפי **חברות, מכשירים ונושאים** — פריט אחד יכול להיות בכמה.

## מה יש
- חיפוש מיידי (גם בלי אינטרנט) בכותרת, בתוכן, בשדות ובשמות התגיות. מספר של 14–15 ספרות = בדיקת IMEI (ספרת ביקורת).
- דפדוף: ראשי (נעוצים, פתחתי לאחרונה, עודכן לאחרונה) / חברות / מכשירים (לפי חברה) / נושאים / סוגים. בחירת כמה תגיות = חיתוך.
- פריט: שדות לפי סוג (קוד, IMEI, כתובת + Waze, טלפון + חיוג, קישור…), תמונות, נעיצה, העתקה ושליחה בוואטסאפ, היסטוריית שינויים ושחזור גרסה.
- ✨ "סדר לי אוטומטית": מדביקים טקסט וה-AI ממלא כותרת, סוג, שדות ותגיות.
- 💬 ייבוא צ'אט וואטסאפ (txt/zip, גם ב"שיתוף" ישר לאפליקציה): ה-AI הופך הודעות לפריטים, עוברים ומאשרים. ההתקדמות נשמרת בטלפון.
- ✨ שאל את המאגר: שאלה חופשית, תשובה רק מהמידע של החנות.
- עובדים: קישור הצטרפות, אישור/דחייה, מנהלים. עובד מוסיף ועורך; מחיקה (עם שחזור) ואישור עובדים — רק מנהל.
- ייצוא לאקסל (CSV) וגיבוי JSON. שיתוף הודעה מוואטסאפ ← "מידע" נכנס כפריט חדש ומסתדר לבד.

## איפה הכול יושב
- **Vercel:** פרויקט `meida` בצוות `myphone3`, Root Directory = `meida`. כתובת: https://meida-myphone3.vercel.app
- **Supabase:** הפרויקט של החנות (`iiaxizrezhczgutqijbe`). טבלאות `kb_shops`, `kb_members`, `kb_tags`, `kb_items`, `kb_history`, דלי `kb-photos`.
  הסכמה ב-`supabase/schema.sql` (כבר הורצה). אין גישה ישירה לטבלאות — רק דרך פונקציות `kb_*` שבודקות שהמשתמש עובד מאושר בחנות.
  אין פקודות delete: מחיקה = `deleted_at`.
- **כניסה עם Google:** Google מחזיר ל-`https://my-phone-iota.vercel.app/meida-auth.html` (קובץ סטטי בחנות), והוא מעביר ל-`/auth` כאן.
  **עובד רק אחרי שהקובץ `public/meida-auth.html` מגיע ל-`main` של החנות.**
- **AI:** `/api/ai` (בודק שהמשתמש חבר בחנות) → השרת של החנות `STORE_AI_URL` עם `STORE_AI_SECRET` (= אותו ערך כמו `WARRANTY_AI_SECRET` בחנות),
  או `GEMINI_API_KEY` ישירות בפרויקט.

## משתני סביבה
`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `STORE_AI_URL`, `STORE_AI_SECRET` (או `GEMINI_API_KEY`).

## שדרוג 2 (נובמבר 2026) — `supabase/schema-2.sql` (הורץ)
- **פתיחת חנות** עם שם, עיר וטלפון (`kb_create_shop2`). עובדים מצטרפים רק בקישור ובאישור.
- **📣 לוח הודעות ומשימות** (`kb_posts`): הודעה / מבצע / מלאי / משימה / תזכורת. טופל/לא טופל (מי ומתי), תוקף עד תאריך, נעיצה, תמונות,
  חיפוש וסינון, חלוקה לפי ימים. "חדש" לפי `kb_members.posts_seen_at`, באנר קופץ בראש המסך ומספר על הכפתור. מחיקה: הכותב או מנהל.
- **🔔 התראות לטלפון** (Web Push, `kb_push`): על הודעה חדשה (`/api/notify`) ועל תזכורות. הפעלה/כיבוי לכל טלפון (`PushToggle`).
- **⏰ תזכורות**: `pg_cron` ב-Supabase קורא כל 5 דקות ל-`/api/cron/remind` עם `x-cron-secret` (= `CRON_SECRET` = `kb_config.cron_secret`).
  תזכורת "רק לי" לא מופיעה לשאר העובדים.
- **📷 סריקת IMEI**: ברקוד חי במצלמה (BarcodeDetector, אנדרואיד) או צילום שה-AI קורא (גם מסך *#06#).
- **📷 צלם וסדר**: צילום מסך/כרטיס ביקור → ה-AI ממלא את הפריט, והתמונה נשמרת בו.
- **🔍 חסר במאגר** (`kb_misses`): חיפושים בלי תוצאה ושאלות בלי תשובה נרשמים, עם כפתור "הוספה".
- **🖼️ תצוגת תמונות** (רשת) לצד רשימה, וסינון "עם תמונות". **פרטים** בכל פריט: מי הוסיף ומתי, מי עדכן ומתי, מקור.
- משתני סביבה נוספים: `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `CRON_SECRET` (כבר מוגדרים ב-Vercel).

## שדרוג 3 — `supabase/schema-3.sql` (הורץ)
- **לוגו לכל חנות** (`kb_shops.logo_url`, `kb_set_logo`): מוצג בראש המסך, ברשימת החנויות ובדף ההצטרפות. מנהל מעלה/מחליף ב"עוד".
  לוגו מובנה: `public/logos/kosher-phone.png` (כשר פון, מתוך kosher-phone.com).
- **💰 בירור מחיר** (`kb_asks`, `kb_answers`): עובד מצלם מוצר ושואל → כל העובדים מקבלים התראה → מי שיודע עונה סכום + הערה →
  השואל מקבל התראה עם המחיר. הראשון מסומן בירוק, אפשר עוד תשובות. סגירה/מחיקה: השואל או מנהל. באנר "מישהו שואל מחיר" במסך הראשי.
- **חיסכון בהעלאות ל-Vercel:** Ignored Build Step — `meida` נבנה רק כשהתיקייה שלו השתנתה, והחנות לא נבנית כשמשתנות רק תיקיות של אפליקציות אחרות.

## שדרוג 4 — אייקון נפרד לכל חנות — `supabase/schema-4.sql` (הורץ)
- כל חנות היא אפליקציה נפרדת במסך הבית: `/api/manifest/<חנות>` (id, start_url ו-scope = `/s/<חנות>`), שם "מידע <שם החנות>".
- האייקון = הלוגו של החנות על רקע לבן: `/api/icon/<חנות>?s=512` (`&m=1` = גרסה עם שוליים לאנדרואיד). בלי לוגו — האייקון הכללי.
  ה-`v` בכתובת משתנה רק כשהלוגו מתחלף, כדי שהטלפון יידע לעדכן.
- `kb_shop_brand` (ציבורית, בלי משתמש): מחזירה רק שם ולוגו לפי מזהה החנות.
- שיתוף מוואטסאפ לאפליקציה של חנות: `/s/<חנות>/share-target` (ה-service worker, ובגיבוי route בשרת).
- התראות מגיעות עם הלוגו של החנות. מי שהתקין לפני כן — מסיר ומתקין שוב מתוך החנות.
- סמל קטן להתראות (הפס העליון באנדרואיד): `public/badge.png` — בועה עם i, לבן על שקוף. באתר החנות: שקית (`/badge-order.png`), כדי להבדיל.
