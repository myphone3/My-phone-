# שלט לטלוויזיה מהטלפון

אפליקציה לטלוויזיית אנדרואיד (Sensor, Android 12) שמאפשרת לשלוט בה מאייפון או מגלקסי דרך הדפדפן.

## איך זה עובד
- **בטלוויזיה:** אפליקציית `שלט מהפון` מריצה שרת קטן על פורט 8080 ושולחת לחיצות דרך ה-ADB של הטלוויזיה עצמה.
- **בטלפון:** נכנסים לכתובת שמופיעה על מסך הטלוויזיה (למשל `http://192.168.1.50:8080`) ושומרים למסך הבית.

## הורדה
גרסה אחרונה (נבנית אוטומטית בכל שינוי):
https://github.com/myphone3/My-phone-/releases/download/tv-remote-latest/tv-remote.apk

## הפעלה ראשונה בטלוויזיה
1. מתקינים ופותחים את האפליקציה.
2. לוחצים על "אודות (Build)" ולוחצים 7 פעמים על Build.
3. לוחצים על "אפשרויות למפתחים" ומדליקים ניפוי באגים (USB / ADB / רשת).
4. כשקופצת השאלה "לאשר ניפוי באגים?" מסמנים "אפשר תמיד" ומאשרים.
